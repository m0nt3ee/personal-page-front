# Personal Page

A modern, performant personal portfolio website built with Next.js, React, and Tailwind.

## Tech Stack

| Technology                                    | Version | Purpose                     |
| --------------------------------------------- | ------- | --------------------------- |
| [Next.js](https://nextjs.org/)                | 16.4.5  | React framework             |
| [React](https://react.dev/)                   | 19.3.0  | UI library                  |
| [TypeScript](https://www.typescriptlang.org/) | 5.9.3   | Type-safe JavaScript        |
| [Tailwind CSS](https://tailwindcss.com/)      | 4.3.5   | Utility-first CSS framework |
| [Bun](https://bun.sh/)                        | 1.3.13  | Package manager & runtime   |
| [ESLint](https://eslint.org/)                 | 9.39.5  | Code linting                |

## Prerequisites

Before you begin, ensure you have [Bun](https://bun.sh/) installed:

```bash
# On macOS/Linux
curl -fsSL https://bun.sh/install | bash

# On Windows
powershell -c "irm bun.sh/install.ps1 | iex"
```

## Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/m0nt3ee/personal-page-front.git
```

2. **Navigate to the project directory**

```bash
cd personal-page-front
```

3. **Install dependencies**

```bash
bun install
```

4. **Start the development server**

```bash
bun dev
```

5. **Open your browser**

> Navigate to [http://localhost:3000](http://localhost:3000) to see your application running.

## Available Scripts

| Command     | Description                          |
| ----------- | ------------------------------------ |
| `bun dev`   | Start the development server         |
| `bun build` | Build the application for production |
